# VIP11 STORE — مشروع متجر عربي للموبايل

واجهة عربية RTL ومتوافقة مع الهاتف، مع تسجيل دخول Google، منتجات وأسعار من Firebase Realtime Database، لوحة إدارة، طلبات محفوظة، وإدارة يدوية للدفع والشحن.

## الحالة الحالية
- إعداد Firebase Web App وRealtime Database أُضيف إلى `firebase-config.js` وفق البيانات التي زودني بها المستخدم.
- يجب إدخال بريد Google الخاص بالمدير قبل تفعيل الموقع.
- لا توجد بوابة دفع أو API شحن تلقائي؛ يراجع المدير التحويل يدويًا ويشحن الطلب من المورد ثم يحدّث الحالة.
- كل طلب يتضمن منتجًا واحدًا وكمية واحدة.

## 1) إعداد المدير
1. تم ضبط بريد المدير في `firebase-config.js` و`database.rules.json` على `bodo36711@gmail.com`.
2. اترك `SETUP_COMPLETE = false` حاليًا. غيّره إلى `true` فقط بعد نشر قواعد الأمان والتحقق من أن دخول المدير يعمل.

## 2) خدمات Firebase
1. في Firebase Console > Authentication > Sign-in method فعّل Google.
2. من Authentication > Settings > Authorized domains أضف نطاق الموقع المنشور.
3. في Realtime Database > Rules الصق محتوى `database.rules.json` بعد استبدال بريد المدير، ثم اضغط Publish.
4. تأكد أن رابط قاعدة البيانات في `firebase-config.js` يطابق الرابط الظاهر في Firebase Console.

## 3) قواعد الأمان
- قراءة بيانات المنتجات عامة لأن أسماء المنتجات وأسعارها معروضة للزوار؛ الكتابة للمدير فقط.
- إعدادات الدفع قابلة للقراءة من واجهة المتجر، والكتابة للمدير فقط. لا تضع أي أسرار فيها.
- العميل يستطيع إنشاء طلب مرتبط بحسابه وقراءة طلباته فقط. لا يستطيع تعديل الطلب بعد إنشائه.
- المدير يستطيع قراءة الطلبات وتحديث حالتها. تحقق من وصول المبلغ بنفسك قبل اعتماد الدفع.
- القواعد تتحقق من الحقول الأساسية، لكنها لا تُعد بديلًا عن مراجعة الأسعار والمدفوعات؛ الشحن يظل يدويًا.

## 4) النشر
ملفات الموقع الثابتة يمكن نشرها على استضافة HTTPS مثل Firebase Hosting أو Netlify. نشر قواعد قاعدة البيانات عبر Firebase CLI يتطلب بيئة تدعم Node.js وFirebase CLI. من مجلد المشروع:
```bash
firebase login
firebase use --add
firebase deploy --only database,hosting
```
اختَر المشروع `vip11-store`. إذا كنت تعمل من الهاتف فقط، لا تشارك كلمة مرور Google أو رموز تسجيل الدخول مع أي شخص؛ استخدم بيئة سحابية موثوقة أو خدمة استضافة تدعم نشر الملفات والقواعد.

## 5) اختبار قبل البيع
1. سجّل دخولًا بحساب المدير إلى `admin.html`.
2. أضف منتجًا تجريبيًا وتأكد أنه يظهر في الصفحة الرئيسية.
3. أدخل بيانات InstaPay وVodafone Cash من لوحة الإدارة.
4. جرّب طلبًا بحساب عميل آخر، وتأكد أن العميل يرى طلبه فقط.
5. اختبر حالات الدفع والطلب يدويًا قبل استقبال أموال حقيقية.

## ملفات المشروع
- `index.html`, `style.css`, `app.js`: واجهة العميل.
- `admin.html`, `admin.js`: لوحة الإدارة.
- `firebase-config.js`: إعداد Firebase وبريد المدير.
- `database.rules.json`: قواعد Realtime Database.
- `firebase.json`: إعداد استضافة الموقع ونشر القواعد.
